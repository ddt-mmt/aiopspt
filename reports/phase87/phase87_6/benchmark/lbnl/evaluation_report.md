# LBNL RTU Benchmark Evidence Closure Report — Phase 87.6

## 1. Overview
This report provides reconstructed confusion matrices and model comparisons for LBNL RTU simulation datasets.

## 2. Key Findings
- Isolation Forest effectively detects severe faults (Condenser Fouling 50% achieving 51.5% recall and 0.589 F1-score).
- Mild faults and undercharge scenarios exhibit lower detection rates, highlighting the need for specialized multivariate feature engineering.
- Statistical thresholds fail entirely on multivariate operational anomalies, confirming the necessity of machine learning ensemble methods.
