# Phase 87.4 — Verified Public Dataset Acquisition & Real-File Validation

This directory contains the complete verification evidence, acquisition manifests, dataset validation reports, benchmark scripts, and final report for Phase 87.4.

## Directory Structure
- `acquisition/`: Acquisition logs, inventory, and SHA-256 checksum manifests.
- `validation/`: Dataset validation JSONs, schema summaries, and data quality report.
- `benchmark/`: Real-file benchmark results for LBNL RTU and NASA Battery #5.
- `evidence/`: Command logs, test results, and evidence manifests.
- `scripts/`: Reusable Python validation and benchmark execution scripts.
